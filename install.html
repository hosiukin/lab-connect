TROUBLESHOOTING

常见问题

90% 的问题来自三件事：EasyConnect 没连、公钥没部署、端口被占用。

macOS 提示“无法验证开发者”，或双击没反应

在 Finder 里右键安装脚本 →“打开”→ 再点“打开”。如果仍被拦截，到“系统设置 → 隐私与安全性”点“仍要打开”；或在终端执行 xattr -dr com.apple.quarantine ~/Downloads/spark-install.command。桌面 App 同理。

Windows 安装包被 SmartScreen / 安全中心拦截

推荐下载 spark-install.exe，下载后双击；它是 NSIS 启动器加配置脚本，不使用 .bat / .vbs，也不调用 cmd.exe。exe 未做代码签名，首次运行 SmartScreen 可能提示：点“更多信息 → 仍要运行”。若安全中心直接隔离，请把文件加入排除项或让管理员放行，不要关闭整个防护。备用入口是纯文本 spark-install.ps1：不要双击，在 PowerShell 中运行 powershell -NoProfile -ExecutionPolicy Bypass -File .\spark-install.ps1；执行策略拦截时先 Unblock-File .\spark-install.ps1。

显示“复用已有密钥”，但提示密钥错误

新版安装器会校验私钥和 .pub。默认路径下损坏或带口令的旧密钥会先备份为 id_ed25519_spark.bak.<时间>，再自动生成新密钥；只是 .pub 过期则会用私钥重新生成，不覆盖私钥；从别的电脑拷来的密钥如果权限过宽，会先收紧权限再验证。自定义路径不会被擅自覆盖，请改用新路径，或先运行 ssh-keygen -p -N '' -f 你的私钥路径 去掉口令。

提示 ssh 退出码 255 / 连接超时

先确认 EasyConnect 已连接，浏览器能打开院内地址；再确认跳板机地址和端口没有变。安装器会把详细日志写到 ~/.spark-dsh/launcher.log（Windows 为 %LOCALAPPDATA%\SparkDSH\launcher.log）。

本地端口 18090 被占用

macOS / Linux：lsof -nP -iTCP:18090 -sTCP:LISTEN；Windows：netstat -ano | findstr 18090。关掉占用的程序，或在上方把本地端口改成 18091 后重新生成安装包。

公钥部署失败，或提示 Permission denied

把安装器显示的 ~/.ssh/id_ed25519_spark.pub 内容导入医院门户的 SSH 公钥设置，然后重新运行安装器。安装器不会保存你的密码。

门户要求登录 / 登录后回到登录页

用 spark 的 Linux 账号和密码登录，不是工号或邮箱。Cookie 有效期为 12 小时；清除浏览器 Cookie 或换浏览器后需要重新登录。

怎么停止隧道或卸载

macOS / Linux 运行 ~/.spark-dsh/uninstall.sh；Windows 在 PowerShell 中运行 powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\SparkDSH\uninstall.ps1"，再删除桌面快捷方式和该文件夹。卸载会移除 ~/.ssh/config 中的受管区块，但保留密钥。

需要管理员权限吗？会上传患者数据吗？

不需要管理员权限，全部安装在用户目录。数据始终留在 spark 服务器，本机只建立 SSH 隧道；安装器和启动器都不会把数据发到院外。

iPad 能直接连接吗？

iPadOS 不能运行安装脚本。最简单的方式是把一台常开的 Windows 电脑做网关：先正常安装并双击 Spark DSH，再从 ZIP 运行 spark-ipad-gateway.ps1（会自动请求管理员权限），让 iPad 和电脑连同一个 Wi-Fi，用脚本打印的 电脑局域网 IP:18091 访问。脚本只放行本地子网；不要映射到公网。
